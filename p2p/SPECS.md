# P2P App

this app lets you communicate and discover threads

## The bottom bar

there will be a status bar that shows 3 numbers

- number of peers connected
- upload bandwidth
- download bandwidth
- number of threads in the db
- number of files in the db
- number of keys in the db

## main page: viewing threads

there is a sidebar with a list of threads, when you click on a thread you can view it. below that thread is all of the reply threads

the user can bookmark threads

the user can compose replies

## public keys page

this page lets the user explore all the public keys they own and have discovered. the user can click on a key to see all of its threads

## files page

lets the user explore files they've downloaded, they can get a backlink to the thread they initially got this file from

## audit log

a running append only log of everything that happens.
